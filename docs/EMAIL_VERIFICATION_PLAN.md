# メール配信の検証プラン

`[[UADDRESS]]` の利用可否とメール送信の確認を段階的に行う。

---

## 検証ステップ

### ステップ1: [[UADDRESS]] が取得できるか確認

**目的**: 外部サイトのフリー領域で `[[UADDRESS]]` が置換されるか検証する。

**作業**:
1. embed に `[[UADDRESS]]` を追加し、API に `email` として渡す
2. 既存の `/api/chat` またはテスト用エンドポイントで `email` を受け取り、レスポンスに含めて返す（ログでも可）
3. 本番サイトのチャットページで送信し、debug 表示やネットワークレスポンスで `email` を確認

**実装済み**:
- embed に `[[UADDRESS]]` を追加
- chat/greeting API に `email` を渡す
- レスポンスに `_email` を含める（検証用）
- デバッグ表示に `email=(none)` または `email=xxx` を表示

**確認方法**:
1. 外部サイトのフリー領域に最新の embed を貼り付け（`[[UADDRESS]]` を含む）
2. チャットページを開き、メッセージを送信
3. 画面下部の debug 表示で `email=xxx` または `uaddress=external` を確認
4. ネットワークタブで API レスポンスの `_email` を確認

**確認結果の記録**:
- [ ] 置換される（有効なメールアドレスが届く）
- [ ] 置換されない（`[[UADDRESS]]` のまま or 空）
- [ ] 外部サイトのドキュメント・設定で置換タグが有効か要確認

---

### ステップ2: メール送信が可能か確認

**目的**: Cloudflare Workers からメールを送れるか検証する。

**選択肢**:
| サービス | 特徴 | 無料枠 |
|----------|------|--------|
| **Resend** | REST API で簡単。Cloudflare Workers との利用例多数 | 月 3,000通 |
| **SendGrid** | 定番。API キーが必要 | 月 100通 |
| **Brevo (旧 Sendinblue)** | 欧州系、日本語対応 | 日 300通 |

**作業**:
1. Resend 等でアカウント作成・API キー取得
2. Workers から `fetch("https://api.resend.com/emails", ...)` でテスト送信
3. 検証用エンドポイント `POST /api/email/test` を作成し、手元から叩いてメールが届くか確認

**確認結果の記録**:
- [ ] 送信成功
- [ ] 送信失敗（理由: _____）

---

### ステップ3: 本番用フローの検討

ステップ1・2 が OK であれば:
- チャット返信時にメール通知を送る
- または「通知設定」でユーザーがメール通知の ON/OFF を選べる（将来）

---

## 次のアクション

1. **embed に [[UADDRESS]] を追加** → ステップ1 の実装
2. **検証用 API を用意** → `email` の受信確認用（chat のレスポンスに含めるだけで可）
3. **Resend 等の導入** → ステップ2 の実装

まずはステップ1（[[UADDRESS]] の取得確認）から進めるのがよい。
